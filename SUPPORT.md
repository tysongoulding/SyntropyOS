## 🐛 3. Filing Bug Reports

When opening an issue, provide:
1. Your OS platform (Windows 11 / macOS / Linux) and architecture (x86_64 / Apple Silicon).
2. Tauri and Rust versions (`tauri info`, `rustc --version`).
3. Steps to reproduce with expected vs. actual behavior.
4. Terminal output or console logs (scrubbing all private keys or personal paths).
